# 算法知识点分类列表

> 涵盖算法竞赛 / 数据结构课程常见知识点，按学习路径分层组织。

---

## 一、基础算法与思想

| 序号 | 知识点 | 说明 |
|------|--------|------|
| 1 | 枚举与模拟 | 穷举所有可能、按规则逐步执行 |
| 2 | 递归与分治 | 大问题分解为子问题、递归求解再合并 |
| 3 | 快速排序 | 分治法 + 基准分区，平均 O(n log n) |
| 4 | 归并排序 | 分治法 + 有序归并，稳定 O(n log n) |
| 5 | 二分查找 | 有序序列中折半搜索，O(log n) |
| 6 | 二分答案 | 将优化问题转化为判定问题 |
| 7 | 高精度运算 | 大整数加减乘除（超出语言整数范围） |
| 8 | 前缀和与差分 | 区间求和 O(1)、区间修改 O(1) |
| 9 | 双指针 | 两指针协同移动，常用于有序数组 |
| 10 | 滑动窗口 | 维护可变长度的连续子区间 |
| 11 | 位运算 | 二进制位的与/或/异或/移位操作 |
| 12 | 离散化 | 将大范围稀疏数据映射到连续下标 |
| 13 | 区间合并 | 将有交集的区间合并为不相交区间集 |

## 二、数据结构

| 序号 | 知识点 | 说明 |
|------|--------|------|
| 1 | 单链表 | 用数组模拟链表，头插/删除 O(1) |
| 2 | 双链表 | 左右指针，支持双向遍历和 O(1) 删除 |
| 3 | 栈 | 后进先出，数组模拟 / 单调栈 |
| 4 | 队列 | 先进先出，数组模拟 / 循环队列 |
| 5 | 单调栈 | 维护栈内元素单调性，求 Next Greater Element |
| 6 | 单调队列 | 滑动窗口最值，队头始终保持区间最优 |
| 7 | KMP | 字符串匹配，前缀函数 + next 数组，O(n+m) |
| 8 | Trie 字典树 | 多字符串前缀存储，高效插入/查询 |
| 9 | 并查集 | 集合合并与查询，路径压缩 + 按秩合并 |
| 10 | 堆 | 完全二叉树，插入/删除 O(log n)，堆排序 |
| 11 | 哈希表 | 键值映射，拉链法 / 开放寻址法 |
| 12 | 字符串哈希 | 将字符串映射为整数，快速判断子串相等 |
| 13 | 树状数组 | 前缀和 + 单点更新，O(log n)，代码短 |
| 14 | 线段树 | 区间查询 + 区间修改，O(log n)，功能强 |
| 15 | 平衡树 | Treap / Splay，动态维护有序序列 |
| 16 | 可持久化数据结构 | 保留历史版本，可持久化 Trie / 线段树 |

## 三、搜索与图论

| 序号 | 知识点 | 说明 |
|------|--------|------|
| 1 | DFS 深度优先搜索 | 递归深入 + 回溯，适合连通性/排列组合 |
| 2 | BFS 广度优先搜索 | 队列逐层扩展，适合无权最短路 |
| 3 | 树与图的存储 | 邻接表 / 邻接矩阵，DFS/BFS 遍历图 |
| 4 | 拓扑排序 | 有向无环图的线性排序，BFS 入度为 0 入队 |
| 5 | Dijkstra | 非负权单源最短路，贪心 + 优先队列 |
| 6 | Bellman-Ford | 可处理负权边，松弛 n-1 轮 |
| 7 | SPFA | Bellman-Ford 队列优化，稀疏图快 |
| 8 | Floyd | 全源最短路，三重循环 O(n³) |
| 9 | Prim | 从顶点出发构建 MST，适合稠密图 |
| 10 | Kruskal | 从边出发构建 MST，并查集判环 |
| 11 | 染色法判定二分图 | DFS 交替染色，无冲突则为二分图 |
| 12 | 匈牙利算法 | 二分图最大匹配，O(nm) |
| 13 | Tarjan 强连通分量 | DFS 序 + low 数组，缩点成 DAG |
| 14 | 最近公共祖先 LCA | 倍增法 / Tarjan 离线，O(log n) |
| 15 | 差分约束 | 不等式组 → 图论最短路模型 |
| 16 | 网络流初步 | 最大流（Dinic）/ 最小割 |

## 四、动态规划

| 序号 | 知识点 | 说明 |
|------|--------|------|
| 1 | 背包问题 | 01 背包 / 完全背包 / 多重背包 / 分组背包 |
| 2 | 线性 DP | 状态按线性顺序转移，如 LIS、编辑距离 |
| 3 | 区间 DP | 状态为区间 [l,r]，如石子合并 |
| 4 | 计数类 DP | 求方案总数，通常需取模 |
| 5 | 数位统计 DP | 按数位逐位统计，如 1~n 中某数字出现次数 |
| 6 | 状态压缩 DP | 用二进制位表示集合状态，如 TSP、状压棋盘 |
| 7 | 树形 DP | 在树上做 DP，通常自底向上 |
| 8 | 记忆化搜索 | DFS + 缓存已计算结果，避免重复计算 |
| 9 | 概率 DP | 状态转移带概率，求期望 |
| 10 | 单调队列优化 DP | 滑动窗口维护决策最优值 |
| 11 | 斜率优化 DP | 将转移方程变形为斜率形式，维护凸包 |

## 六、数论与数学

| 序号 | 知识点 | 说明 |

## 七、贪心

| 序号 | 知识点 | 说明 |
|------|--------|------|
| 1 | 区间选点 | 按右端点排序，每次选最右点覆盖尽可能多区间 |
| 2 | 区间覆盖 | 从左到右，每次选能覆盖当前起点的最远区间 |
| 3 | 区间分组 | 将区间分为最少组，使组内无交集 |
| 4 | Huffman 树 | 贪心合并最小两堆，求最优前缀编码 |
| 5 | 排序不等式 | 大配大 / 小配大原理 |
| 6 | 绝对值不等式 | |x-a|+|x-b| 最小值在 a,b 之间 |
